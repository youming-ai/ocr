# OCR — Your Files Never Leave Your Device

## About
OCR is a privacy-first on-device OCR tool powered by PaddleOCR PP-OCRv6. Extract text from images and PDFs — source files stay in your browser. OCR processing runs locally via ONNX Runtime Web (WASM).

## How It Works
1. User uploads an image or PDF (drag & drop, paste, or file picker)
2. PP-OCRv6 runs in the browser via ONNX Runtime Web (WASM) — no server upload
3. Two-stage pipeline: text detection → text recognition

## Features
- On-device OCR — source files never leave your browser
- Reliable English (ASCII) text, numbers and symbols
- Image and PDF support

## Known limitation
- Non-ASCII scripts (Chinese, Japanese, accented Latin, …) are not reliably
  recognized yet: the released PP-OCRv6/v5 unified recognition models transcribe
  non-ASCII text as byte sequences, an upstream issue tracked at
  https://github.com/youming-ai/ocr/blob/main/docs/upstream-rec-non-ascii.md

## Privacy
- OCR runs entirely in-browser — no file uploads to any server
- No AI/LLM processing is used; extracted text is not sent anywhere
